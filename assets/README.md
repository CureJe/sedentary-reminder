# Character Assets

- `characters/cat.png`, `corgi.png`, `red-panda.png`, and `mech.png` were generated from the approved project concepts and processed locally into transparent PNG files.
- `characters/web-ranger.png` is the original **Web Ranger** character created for this open-source release. Its deep navy, copper-orange, graphite, and cyan design does not use Marvel characters, movie costumes, spider emblems, or third-party trademarks.
- `source/web-ranger-chroma.png` is the flat-background generation used to create the transparent Web Ranger cutout.

The public repository does not contain the third-party movie references or personal-use-only assets used during early private prototypes.
